# Vue 小朋友遊戲天地 🎮

這是一個為 8 歲小朋友設計的互動遊戲平台，包含 3 款有趣的遊戲。

## 🎯 功能特色

### 1. 🧠 記憶大師
- **玩法**：配對相同的動物卡牌
- **特點**：
  - 可愛的動物圖案 (🐶 🐱 🐻 🐼 🐨 🐯)
  - 翻牌動畫效果
  - 計數點擊次數和配對次數
  - 完成時顯示所用時間
  - 根據表現給予評價

### 2. 💣 數字炸彈
- **玩法**：在時間內點擊正確的數字
- **特點**：
  - 進度條倒計時
  - 生命值系統（3 條命）
  - 難度逐漸增加
  - 實時分數計算
  - 成功和失敗統計

### 3. 🎨 旋轉顏色
- **玩法**：點擊指定顏色的方格
- **特點**：
  - 6 種漂亮的顏色
  - 8 個難度等級
  - 進度條顯示
  - 等級系統
  - 分數累積

## 🚀 開始使用

### 安裝依賴
```bash
npm install
```

### 開發模式
```bash
npm run dev
```

### 構建生產版本
```bash
npm run build
```

## 🎮 遊戲說明

### 記憶大師
1. 選擇「記憶大師」開始
2. 點擊卡牌翻開
3. 配對所有相同的動物
4. 記錄您的最佳成績！

### 數字炸彈
1. 看顯示的目標數字
2. 在時間內找到並點擊
3. 每次成功會增加難度
4. 失敗 3 次遊戲結束

### 旋轉顏色
1. 根據提示點擊對應顏色
2. 每 5 次成功升一級
3. 最高 8 級
4. 挑戰高分！
